# README
This is our project for DIT1323 Java Programming in January 2024 Sunway College in Sunway College.

## QN1 
QN 1 is a currency calculator app, that converts any amount to MYR, that is made using JOptionPane as the GUI, user enters, 
the currency type, the amount they want to convert, the exchange rate, it also includes in an adminrate which deducts the total currency exchange amount, based on the amount of currency exchanged. Not only that, it also has error checkings.
For example, preventing user from entering characters, or alphabets, into the amount entered, etc.

## QN 2
QN 2 is a student report generator, using CLI, it receives input such as student ID, name, level, and scores for 6 subjects, then it returns the report of the student, including additional information such as, total score, average score, and maximum score.
It also contains error checking.
